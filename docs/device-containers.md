# 设备容器桥接

宿主 Forge 1.20.1 的菜单接收窗口、槽位与光标同步，点击交给原始 1.7.10 `Container.slotClick`。旧 FML GUI handler 和直接打开 `IInventory` 的请求都接入此路径；客户端继续绘制原始 GUI。JEI 是当前图形测试环境，NEI 兼容代码保留。

服务端点击在设备事务内执行，沿用原始槽位限制、转移与抛出算法。原始抛出动作生成现代掉落物；关闭时由宿主处理光标物品，避免客户端旧关闭回调重复抛出。旧玩家统计值在旧运行时内存中记录，不代表现代统计或成就已经接入。

客户端同类型的设备 NBT 更新保留旧对象身份，以维持打开界面的引用。NBT 中的旧 TileEntity 注册 ID 决定实际类型；普通桌转换为研究台等类型变化会替换对象。保存后的恢复也使用该 ID，避免只根据方块和 metadata 猜测类型。

旧世界的范围实体查询映射到宿主实体。设备更新范围内的速度与坠落距离变化在事务成功后提交；已验收原始升降机驱动现代掉落物。此接口不是完整旧实体 AI 或实体状态模拟。

## 验证

使用隔离构建输出、独立游戏目录及原始 TC4/Baubles 样本，运行 `-PmfclDeviceSmokeTest`。报告位于游戏目录 `logs/mfcl/device-smoke.json`，截图位于 `screenshots/device-*.png`。
