# Extra Utilities 物品使用审计（2026-10-22）

环境：Forge 1.20.1-47.4.28、Java 17、原始 Extra Utilities 1.2.12，通过 MFCL 私有 Forge 1.7.10 运行时执行。测试使用独立目录和新建的临时平坦世界。

## 批量回调实测

`ItemUseHostAudit` 枚举注册物品的原始方法覆盖情况，对 415 个物品/变种执行适用的空中右键、石头目标使用和背包更新回调。原生客户端、集成服务器和原始模组代码均实际运行。

| 结果 | 变种数 | 含义 |
| --- | ---: | --- |
| CALLBACKS_RETURNED | 412 | 本次调用没有抛异常或返回 FAIL，不代表物品的全部功能正常 |
| FAIL | 0 | 修复后未再出现初次审计的 5 项失败 |
| NO_DIRECT_USE | 3 | 没有本次检查的直接使用回调 |

初次审计记录了 407 项回调返回、5 项失败；后续修复如下：

| 物品 | metadata | 原因及修复 |
| --- | ---: | --- |
| ExtraUtilities:glove | 0 | 原始背包刷新访问旧服务器；映射玩家改由宿主提交和同步背包 |
| ExtraUtilities:mini-soul | 0、3 | 补齐原始玩家属性注册及宿主基础值、永久/临时修饰符双向同步 |
| ExtraUtilities:datablock | 0 | 隐藏颜色数据方块原本就没有可见模型，允许其原始空几何 |
| ExtraUtilities:endConstructor | 0 | 原始实体构造播放声音阻断模型预览；预览期间静音，保留正式运行的声音入口 |

此统计不能用作“412 个物品功能通过”的结论。批量部分只给出一种通用目标，未覆盖材料需求、蓄力完成、所有伤害/附魔、NBT 状态、全体客户端视觉效果或放置后设备的长期运行。下列目标场景另行验收。

## 本轮修复与回归

- 物品右键及方块使用捕获原始 FML GUI 请求，使用原生菜单同步；之前只有方块激活接入。
- 便携菜单标记随开窗数据发送，跳过方块坐标距离限制，事务锚点使用玩家位置；原始容器的有效性检查继续执行。通道版本更新为 6。
- 构造原始客户端 GUI 前投影玩家背包和选中槽位，补齐映射玩家的原始背包容器。
- 安装天使之戒的现代 Forge 监听器时使用宿主类加载上下文，避免私有旧版加载器参与现代事件类变换。
- 接入实体交互、武器命中、挖掘回调和主手原始属性；套索携带宿主实体完整 NBT，释放时恢复宿主实体。
- 精准剪刀写回宿主羊的剪毛状态；原始掉落实体在提交前参与收集，避免羊毛重复生成。
- 旧 Forge 区块票据初始化和 force/unforce/release 接入宿主区域票据，保留独立所有者、旧数量限制和淘汰顺序；世界卸载时清理。
- 客户端玩家渲染层调用原始翅膀绘制，使用原贴图和振翅角度，再附着到新版玩家身体姿态。监听器安装检查预加载声明，避免物品注册前查询空映射而跳过安装。

原始金色背包的隔离集成回归覆盖 GUI 捕获、非零快捷栏槽位、90 个槽位、原始点击逻辑、存入物品的 NBT 和重新投影背包后的读取。

最终原生验收也通过：

- 金色背包在第 6 个快捷栏槽位打开客户端原始界面，保持有效；经原生槽位点击存入 3 个石头，关闭重开后仍为 3 个。
- 生存模式背包中的天使之戒授予宿主飞行权限；移除后，原始到期回调收回权限。
- 金色套索捕获并释放命名幼年猪，保留 UUID、名称、年龄、生命值和宿主持久数据。
- 分裂迷你灵魂降低宿主最大生命值并写入永久属性修饰符；使用后恢复并消耗物品。
- 精准剪刀改变宿主蓝羊的剪毛状态，羊毛进入背包且重复交互不复制羊毛，工具正常损耗。
- 以太剑向宿主攻击属性提供原始修饰符，原生攻击造成伤害；毁灭镐具备原始石头挖掘速度和采集资格，保留原版无损耗行为。
- 黄金之翼（metadata 4）捕获到原始 8 个顶点与 `wing_golden.png` 贴图；切换第三人称后玩家渲染层实际执行 112 帧，人工检查截图确认两侧黄金翅膀可见。原生审计最终状态为 `COMPLETED`，415 项中无调用失败。只捕获到几何而没有实际绘制的前次截图不计为通过。

`test assemble`：119 项测试中 109 项通过、10 项因缺少其他可选输入跳过，失败和错误均为 0。原始套索与区块票据回归覆盖完整载荷往返、两个所有者共享区块、深度淘汰和释放。
构建产物为 `build/item-repair/libs/mfcl-0.2.8.jar`。新增渲染类需要完全重启游戏后加载。

## 验收边界

通用 MirroredItem 已转发实体交互、命中、挖掘和属性入口；上述具体场景不代表每种特殊工具能力、旧 Forge 全局事件和现代模组新增方块均已覆盖。未逐一验收扫描仪目标、全部武器特殊效果、所有附魔和多人远端玩家视觉同步。Baubles 佩戴槽未接入。

初次批量放置期间抽熔岩泵在旧 `ForgeChunkManager.requestTicket` 的异常已修复；本次不宣称已验证其长时间抽取、跨区块流体传输和重启恢复的全部行为。

## 复现

原生实测目录需要在 `mods/1.7.10` 放入原始 Extra Utilities JAR，并在 `options.txt` 设置 `onboardAccessibility:false`。运行：

```powershell
.\gradlew.bat --offline --project-cache-dir build/item-audit-client-cache `
  -I tools/isolated-build.init.gradle -PmfclValidationBuildDir=build/item-audit-client `
  runClient -PmfclRunDir=build/item-audit-game `
  -PlegacyRuntimeDir=build/nei-investigation/runtime -PmfclItemAudit
```

报告位于 `build/item-audit-game/logs/mfcl/item-use-audit.json`。该模式还执行上述目标场景，切换第三人称，检查翅膀玩家渲染层实际执行，再保存 `screenshots/mfcl-golden-wings.png` 供人工看图验收。完成结果须检查报告、日志和截图，不能仅以 Gradle 进程退出成功或捕获到顶点为准。
