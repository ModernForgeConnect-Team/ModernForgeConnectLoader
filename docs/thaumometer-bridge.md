# 魔导透镜扫描桥接

2026-10-19，Forge 1.20.1 / Java 17，原始 Thaumcraft 4.2.3.5。

对照原 `ItemThaumometer`、`ItemThaumometerRenderer`、`ScanManager` 和 1.7.10 `Item` 的射线计算实现。

右键普通方块不再被客户端的方块使用结果提前吞掉，而是进入原物品的持续使用流程。按住右键扫描约一秒，中途松开取消；原代码实际成功时发出的扫描请求经过宿主连接送到服务器。服务器重新计算视线目标并调用原 `completeScan`，原有前置要素要求继续生效。

单机客户端与服务端的原始研究数据分开保存，避免客户端先标记“已扫描”影响服务端奖励。研究、要素和扫描记录通过原始 NBT 保存方法写入宿主玩家存档，原始同步消息负责更新客户端。

第一人称渲染使用实际玩家和世界重新执行原透镜渲染器，能读取当前目标与扫描记录，绘制要素图标和文字。玩家眼高按 1.7.10 客户端、服务端各自的坐标约定转换。新世界刚载入、尚未经过首个客户端 tick 时也能建立世界绑定，避免读档手持透镜崩溃。

后续修复看向 `minecraft:oak_fence` 时的崩溃：世界读取共用原有物品变体表反向转换旧方块名称，并转换原木轴向、台阶上下半部、楼梯方向等旧 metadata。栅栏连接、玻璃板连接等状态不会改变原物品身份。此映射用于读取；世界写入仍使用独立验证的写入映射。

遇到深板岩、红树木栅栏等没有旧方块表示的目标时，第一人称保留原始空闲透镜与手部模型，省略要素覆盖层并记录一次诊断；不伪造旧方块或扫描奖励。该回退仅处理明确的方块映射缺失，其他渲染错误仍会暴露。

`-PmfclScannerSmokeTest` 使用隔离游戏目录自动验证。报告见 [thaumometer-progress.json](thaumometer-progress.json)：

- 真实右键方块后进入持续使用状态。
- 首次扫描石头，Terra 增加 2，客户端与服务器一致，镜面捕获 Terra 图标。
- 原扫描快门声与完成奖励提示进入实际音频通道，见 [legacy-sounds.md](legacy-sounds.md)。
- 重复扫描不重复奖励，中途取消不完成扫描。
- 未知复合要素的前置检查和原始提示生效。
- 退出并重新载入世界后，服务器扫描记录和要素数量保留，并同步到客户端。
- 同时验证 JEI 同类物品预览和 116 个携带原始 NBT 的神秘时代物品变体。
- 重载后依次看向 13 个目标，验证橡木栅栏、不同轴向原木、彩色羊毛/玻璃板、上半台阶、楼梯、石英柱、草方块、雪块的旧名称与 metadata；深板岩和红树木栅栏回退后再看向石头，渲染正常恢复。

魔导手册的原右键打开、研究同步、4 个条目悬停、`ENCHANT` 正文、分类切换和 Esc 关闭回归通过。声音修复后 JUnit 51 项通过、4 项缺少外部样本跳过，`test assemble` 成功。验证产物复制至 `build/libs/mfcl-0.1.0.jar`。

此轮功能验收覆盖方块扫描。生物、掉落物以及所有节点种类的扫描仍需要各自的实体、节点桥接验收，不代表已全面兼容。
